# Precomputed studio reflections

Original Three.js RoomEnvironment, generated once with three@0.187.0 PMREMGenerator.fromScene(room, 0.03). The 256px cube has six filtered levels (256…8); the mobile 128px cube uses the lower five levels. Linear RGBA half floats retain five mantissa bits to reduce transfer size. No external HDR image.

Gzip payload: 4 little-endian uint32 values (magic 0x504d524d, version 1, face size, level count), followed by RGBA half floats in mip-major, +X/-X/+Y/-Y/+Z/-Z face order. Origin matches WebGL texture memory. All levels are prefiltered, not generated by visitors.

To rebake, use scripts/bake_environment.html with its module while serving a staging directory containing only those two bake files and vendor/three, then run scripts/prepare_environment.py on the exported gzip file.
